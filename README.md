# Guia Inglaterra

Guia de viagem offline (PWA), exportado do Claude Design.

- Android (Chrome): abrir o link → ⋮ → "Instalar app"
- iPhone (Safari): abrir o link → Compartilhar → "Adicionar à Tela de Início"

Ao alterar qualquer arquivo, suba a `VERSION` em `sw.js` para os celulares baixarem a nova cópia.
